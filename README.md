# student-attendance-tracker

Приложение для учета посещаемости студентов.

## Функциональность

- три роли: администратор, менеджер и староста;
- староста видит только свою группу;
- менеджер видит общую таблицу по всем группам;
- данные сохраняются на сервере в SQLite;
- запрещена отметка будущих дат;
- адаптивный интерфейс для ПК и мобильных устройств.

## Требования

- Node.js 18+
- Ubuntu 24.04 / 26.04 или другой Linux-сервер
- доступ по SSH к серверу Timeweb Cloud

## Быстрый старт

1. Подготовьте `.env` на основе `.env.example`.
2. Укажите значения для `JWT_SECRET`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `MANAGER_LOGIN`, `MANAGER_PASSWORD`, `STAROSTA_DEFAULT_PASSWORD`.
3. Установите зависимости:

```bash
npm install
```

4. Запустите инициализацию базы данных:

```bash
npm run setup-db
```

5. Запустите приложение:

```bash
npm start
```

После запуска приложение будет доступно на `http://localhost:3000`.

## Безопасность

- пароли хранятся только в виде хешей (`bcrypt`);
- токены выдаются после успешного входа;
- доступ к данным определяется ролью пользователя;
- в репозиторий не включаются реальные пароли.

## Переменные окружения

Создайте `.env` на базе `.env.example`:

```bash
cp .env.example .env
```

Заполните значения, но не публикуйте их в публичных репозиториях.

## Развертывание на сервере Timeweb Cloud

1. Подключитесь к серверу по SSH.
2. Загрузите проект на сервер.
3. Установите зависимости через `npm install`.
4. Создайте `.env`.
5. Запустите `npm run setup-db`.
6. Запустите приложение через `npm start` или PM2.

### PM2 (рекомендуется)

```bash
npm install -g pm2
pm2 start server.js --name attendance-app
pm2 save
```
